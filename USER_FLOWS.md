# User flows

## Account and onboarding
Choose locale → register email/password → confirm 18+ → verify email → enter DOB → server checks age → country → purposes (at least one) → profile → languages → interests → photos → safety introduction → completion. Discovery hides incomplete/suspended profiles. DOB stays private; derive age. Reject future dates and under-18 users server-side and at the database write boundary.

## Connections
Discover with bounded filters and cursor pagination → view limited profile → express interest → atomic reciprocal interest creates one match/conversation → text messages. Recheck membership, blocks and suspension on every send/read. Block immediately removes interaction access; reports remain available and preserved for staff review under retention rules.

## Marriage support
Voluntary private relationship progression → optional Marriage Journey → destination/citizenship combination → current versioned checklist → progress and notes → optional professional-service quote. Always show the requirements-change warning and official references. No automatic legal conclusions.

## Professional order
Select active service → describe request/language pair/page count → upload to quarantine → validate and scan → staff review → quotation → customer acceptance → awaiting payment → verified payment event → work → quality review → completion notice. Customers cannot set prices, staff roles or paid state. No public document URLs.

## Booking
Service → available slot in displayed timezone → notes → request → staff confirmation. Transactional conflict protection prevents double booking. Provider calendar integration comes later.

## Administration
Verified staff session → role check → scoped queue → review evidence → reasoned decision → append audit entry → notify affected customer as appropriate. Staff may access only assigned orders; only administrators manage role grants and suspensions. Staff cannot grant themselves access.

## Privacy
Settings → edit visibility/photos → deletion request → retention/active-order review → erase/anonymize eligible data. Export requests require reauthentication; future export delivery must be temporary and private.
